Litefin

This plugin provides secure backup and restore storage for Litefin clients. Administrators can configure optional server integrations and manage stored backups below.

Seerr Integration

Configure Seerr once on the server. Litefin clients use their existing Jellyfin session and never receive the API key. Jellyfin users must also be imported into Seerr for requests to be attributed correctly.

The full URL of the Seerr instance, without /api/v1.
Stored in the Jellyfin plugin configuration and never returned by the Litefin Seerr API.
